# مختبر الفيزياء — السادس العلمي

**افتح المختبر:** https://imadmfas.github.io/physics6/

كتاب الفيزياء للصف السادس العلمي (الطبعة الحادية عشرة 2025) تفاعليًا، ضمن منصة «اللوح المحاور».

## ما فيه

- **أجنحة المختبر:** كل فصل جناح، ويُفتح الجناح التالي بعد اجتياز «تحدّي الجناح» بدرجة 80%.
- **المهام:** كل درس مهمة فيها بطاقات الشرح من نص الكتاب، والقوانين، والأمثلة المحلولة خطوة خطوة، وتجربة افتراضية بمهام صغيرة، وسؤال تحقق، ثم اختبار المهمة بثلاث نجوم.
- **بنك الوزاريات:** أسئلة الامتحانات الوزارية من 2013 إلى 2026 بسنواتها وأدوارها، مع تصفية بالسنة والنوع.
- **تحدّي الأرقام:** مسائل عددية جديدة في كل مرة تُصحّح آليًا.
- **بطاقات المراجعة، وتحدّي اليوم، والامتحان الوزاري التجريبي** بمؤقت ثلاث ساعات.
- **التلعيب:** نقاط خبرة ورتب، وإلكترونات، وسلسلة أيام، وأوسمة، وأصوات ومؤثرات.

الدرس الأول من كل فصل مجاني، وبقية الكتاب لمشتركي السادس العلمي في «اللوح المحاور».
يُحفظ التقدّم على جهاز الطالب فقط.

## للمطوّر

```bash
npm ci
python3 tools/build_ch1.py   # يبني data/ch1.json
python3 tools/lint_ar.py     # فحص الصيغ العربية الممنوعة
node build.mjs               # يبني app.js و index.html
```

إعداد الأستاذ الدكتور عماد محمد فرحان الدليمي، باستعمال المساعد الذكي كلاود (Claude).
